# fp_fiber3

MPS solver for fiber suspensions.

## Features

- Shear (Couette) flow with both walls moving, or pressure-driven (Poiseuille) flow
- Fiber-fiber interactions
- Fibers are represented as particles connected by stretching (`ks`) and bending (`kb`) springs
- Cell list for neighbor search
- Non-dimensionalized equations
- Pressure: implicit, solved with PETSc (single node)
- Optional OpenMP parallelization

|                | Poiseuille | Couette |
|:--------------:|:----------:|:-------:|
| `Gravity`      | > 0.0      | = 0.0   |
| `strain_rate`  | = 0.0      | > 0.0   |

## Executables

| Target | Source | Build |
|--------|--------|-------|
| `mps` | `main.c` | `make` |
| `init` | `init.c` | `make` |
| `mps_omp` | `main.c` (OpenMP) | `./omp.sh` |

`init` relaxes the configuration generated by `../mk_fiber` (runs at zero shear rate) and is called from `output/mk_fiber/mk_particle.sh`.

## Usage

```sh
path/to/mps input.txt
```

See the top-level [README](../../README.md) for the input file format and output files.
The directory given by `output_dir` must exist.
